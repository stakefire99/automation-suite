# AutoSuite - Automation Control Center

## Overview

AutoSuite is a modern React-based automation dashboard designed to provide a centralized interface for monitoring and managing automation workflows. The dashboard features a futuristic control-center design and includes modules for file organization, web scraping, email automation, system monitoring, and task scheduling.

## Features

### Overview Dashboard

* Real-time statistics and performance metrics
* Resource usage monitoring
* Productivity and efficiency insights

### File Organizer

* File categorization dashboard
* Storage distribution visualization
* File monitoring statistics

### Web Scraper

* Active scraping job monitoring
* Success rate tracking
* Data collection analytics

### Email Automation

* Email campaign management interface
* Template performance tracking
* Open-rate monitoring

### System Monitor

* Live CPU, memory, disk, and network monitoring
* Dynamic performance visualization
* System status alerts

### Task Scheduler

* Scheduled task overview
* Upcoming automation jobs
* Recurring task management

## Technologies Used

* React.js
* JavaScript (ES6+)
* React Hooks (useState, useEffect)
* CSS-in-JS Styling
* Vite Development Environment

## Installation

1. Install Node.js
2. Create a React project using Vite
3. Copy the AutomationSuite component into the src folder
4. Install dependencies

```bash
npm install
```

## Run the Project

```bash
npm run dev
```

Open the local development URL displayed in the terminal.
